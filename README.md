# 가상화 기반 Solution Engineer Academy — 과정 안내 페이지

굿모닝아이텍(주) 선도기업 아카데미(2027 K-디지털 트레이닝) 과정 소개·훈련생 모집용 정적 웹페이지입니다.
빌드 도구 없이 HTML·CSS·JavaScript만으로 동작하며 GitHub Pages에 그대로 배포할 수 있습니다.

## 폴더 구성

```
index.html          페이지 본문 (정적 텍스트 — 검색엔진 노출 대상)
css/style.css       디자인 토큰과 레이아웃
js/data.js          교과목·월차 편성·직무·프로젝트·일정·상담 링크 데이터
js/main.js          카운터, 탭, 자가 확인, 간트, 스크롤 동작
assets/             로고(굿모닝아이텍·한국정보교육원 가로/세로/흰색), BHA·우수훈련기관 인증마크
```

## GitHub Pages 배포

1. GitHub에서 새 저장소 생성 (예: `git-se-academy`)
2. 이 폴더의 파일 전체를 저장소 루트에 업로드 (`index.html`이 루트에 있어야 함)
3. 저장소 **Settings → Pages → Build and deployment**
   - Source: `Deploy from a branch`
   - Branch: `main` / `/ (root)` 선택 후 Save
4. 1~2분 후 `https://<계정명>.github.io/<저장소명>/` 에서 확인

## 내용 수정 위치

| 수정할 내용 | 파일 |
| --- | --- |
| 상담 신청·카카오톡 링크 | `js/data.js` → `links` |
| 교과목 시간·세부내용 | `js/data.js` → `subjects` |
| 월차별 편성 | `js/data.js` → `months` |
| 진출 직무와 연계 교과 | `js/data.js` → `roles` |
| 프로젝트 과업·사례·구성도 | `js/data.js` → `projects`, `DIAGRAMS` |
| 연간 일정(간트) | `js/data.js` → `gantt` (열 0 = 2026년 11월) |
| 모집 문구, 지원자격, FAQ, 회사 수치 | `index.html` |
| 적합도 확인 배점 | `js/main.js` → `W` (학력 40/15, 경력 20/5, 전공 20/10, 학습경험 20/10) |

숫자 애니메이션은 `<span class="num" data-count="값">값</span>` 형태로 넣으면 자동 적용됩니다.
소수점은 `data-decimals="1"`, 천 단위 쉼표를 빼려면 `data-plain`을 추가합니다.

## 확인이 필요한 항목

- 모집 일정: 운영계획서 표 기준 1기 2026.12~2027.01, 2기 2027.06~2027.07로 표기 — 공고 확정 시 수정
- 취업지원 기간: 1기 2027.04~08, 2기 2027.10~2028.01로 표기
- 유관기업 채용수요 5~9명으로 표기, 기업명은 비공개
- 한국정보교육원 실적(취업률 82.8%, 수료율 90.6%)은 운영계획서 파트너기관 실적 기준
- 교강사 실명은 미표기, 역할 중심으로 작성

## 추가하면 좋은 이미지

`assets/`에 넣고 `index.html`에서 참조하면 됩니다.

- 굿모닝아이텍(주) 로고 SVG 또는 고해상도 PNG(가로 600px 이상, 투명 배경)
- 한국정보교육원 실습실·프로젝트룸 실사진
- 현직자 멘토링·프로젝트 발표회 사진 (초상권 동의 필요)
- SNS 공유용 대표 이미지 1200×630 (`og:image`)
